1. Ringkasan Eksekutif (Executive Summary)

Dalam ranah e-commerce, fase komunikasi pra-penjualan (pre-sales dialogue) merupakan momen paling menentukan bagi calon pembeli sebelum mengambil keputusan transaksi. Pemanfaatan Large Language Model (LLM) secara mandiri (standalone) dalam domain ini kerap menghasilkan masalah fatal berupa halusinasi produk (merekomendasikan barang fiktif) dan pelanggaran batas anggaran (budget non-compliance). Di sisi lain, sistem rekomendasi konvensional (CRS) unggul dalam akurasi katalog namun kaku dan tidak persuasif.

Hasil Inti Pengujian Sistem: Berdasarkan 10 skenario kueri pembeli riil, kolaborasi CRS + LLM di Campus Market berhasil menekan Hallucination Rate dari 75,0% (pada LLM murni) menjadi 0,0%, sekaligus mendongkrak Budget Compliance Rate dari 25,0% menjadi 100,0%.

2. Landasan Teori: Konsep "Made for Each Other"

Mengacu pada paper acuan ilmiah “Conversational Recommender System and Large Language Model Are Made for Each Other in E-commerce Pre-sales Dialogue”, kedua teknologi memiliki karakteristik komplementer:

  • CRS sebagai Komponen Objektif (Objective Selector): Bertanggung jawab menyaring inventaris katalog secara matematis berdasarkan kategori, batas harga maksimal, dan preferensi profil pengguna.
  • LLM sebagai Komponen Subjektif (Subjective Communicator):** Bertanggung jawab menyusun narasi bahasa alami yang ramah, santun, dan menjelaskan keunggulan fitur (*value proposition*) kepada calon pembeli.

3. Arsitektur Dua Tahap (Two-Stage Grounded Pipeline)

Alur kerja pemrosesan percakapan konsultasi di Campus Market dirancang dalam alur deterministik:

  1. Langkah A — Ekstraksi Niat (Intent Extraction): Menganalisis kalimat pembeli untuk mengekstrak kategori barang, batas anggaran (rupiah murni), dan kata kunci spesifik.
  2. Langkah CRS — Filtering & Scoring: Menyaring 30 produk katalog lokal menggunakan formula multi-faktor (skor 0–100) dan memilih Top-4 kandidat terbaik.
  3. Langkah B — Pembangkitan Dialog Terpandu (Grounded Prompting): Menyuntikkan metadata kandidat terpilih ke prompt sistem Gemini 1.5 Flash untuk menghasilkan jawaban persuasif dalam format JSON baku: { reply, recommendedProductIds }.
  4. Lapisan Anti-Halusinasi (Strict ID Validator): Memeriksa setiap ID produk dari respons LLM terhadap whitelist inventaris resmi. ID fiktif langsung dieliminasi sebelum mencapai antarmuka web pengguna.
